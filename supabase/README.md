# تغييرات قاعدة البيانات (Supabase)

كل تعديل على القاعدة يُكتب هنا ملفًا قبل تطبيقه، ولا يُطبَّق على القاعدة الفعلية إلا بعد موافقة صاحب المنصة.

| المجلد | المحتوى |
| --- | --- |
| `migrations/` | التعديل نفسه، بترتيب التاريخ |
| `rollback/` | ملف يعيد الحالة السابقة حرفيًا لكل تعديل |
| `tests/` | اختبار يُشغَّل على نسخة محلية مسترجعة من النسخة الاحتياطية، ثم يطبّق التعديل والتراجع ويقارن |

خطوات أي تعديل:

1. نسخة احتياطية جديدة قبل التطبيق.
2. تشغيل الاختبار على نسخة محلية حتى تنجح كل الفحوص.
3. مراجعة الـ Pull Request والموافقة عليه.
4. تطبيق ملف `migrations/` على القاعدة الفعلية.
5. عند أي مشكلة: تطبيق الملف المقابل في `rollback/`.

لا تحتوي هذه الملفات أي بيانات طلاب أو كلمات مرور أو مفاتيح.
