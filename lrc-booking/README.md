# مركز مصادر التعلم – نظام الحجز الإلكتروني

مدرسة الشيخ سعيد بن حمد الحارثي · **المرحلة الأولى: واجهات تجريبية فقط (بيانات وهمية)**

```bash
cd lrc-booking
npm install
npm run dev      # تشغيل محلي
npm run build    # بناء نسخة ثابتة في dist/
```

## حسابات تجريبية (أرقام وهمية)
| الدور | الرقم |
|---|---|
| معلم | 100100 |
| مسؤول مركز المصادر | 200100 |
| إدارة المدرسة | 300100 |

> الدخول بالرقم الوظيفي وحده **تجريبي فقط**؛ وسيلة التحقق الآمنة تُحدد في مرحلة ربط الحسابات.

## البنية
- `src/types.ts` — أنواع النطاق.
- `src/data/repository.ts` — واجهة مصدر البيانات (العقد بين الصفحات والبيانات).
- `src/data/mock/` — تنفيذ تجريبي في الذاكرة. لاحقاً يُضاف `SupabaseRepository` ويُبدّل في `src/data/index.ts` فقط.
- `src/lib/schedule.ts` — الحصص والأوقات والأسابيع (تعديل أوقات الحصص من هنا).
- `tailwind.config.js` — ألوان الهوية (الكحلي، الأزرق الفاتح، ألوان الحالات).
