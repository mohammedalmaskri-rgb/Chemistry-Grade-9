## استبدال الصوت بتسجيل بشري

1. **مقطعًا بمقطع:** سجّل كل مقطع بالاسم نفسه (`n01.mp3` …) وضعه في المجلد أعلاه ثم شغّل `npm run check` للتأكد من أن المدد تناسب الفواصل (حدّث المدد بتشغيل `npm run voice` مع `SKIP_TTS=1` أو عدّل `start`).
2. **ملفًا واحدًا كاملًا:** سجّل التعليق كاملًا متزامنًا مع التوقيتات أدناه، وضعه في `public/audio/voiceover-full.mp3`، ثم عيّن `AUDIO.externalVoiceFile = "audio/voiceover-full.mp3"` في `src/config.ts`.
