تحديث بنك الأسئلة - حالات المادة (15 سؤالًا)

المحتويات:
1) index.html
2) question-bank-addon.js
3) question-bank-addon.css
4) add_15_states_questions.sql
5) questions_15_ar.txt

طريقة التركيب:
1. ارفع index.html و question-bank-addon.js و question-bank-addon.css إلى مستودع GitHub نفسه وفي نفس مكان app.js.
2. سجّل دخولك في المنصة بحساب المعلم.
3. افتح Supabase > SQL Editor.
4. شغّل ملف add_15_states_questions.sql كاملًا مرة واحدة.
5. بعد نجاح التنفيذ، افتح المنصة بحساب طالب > بنك الأسئلة > الوحدة الأولى > حالات المادة.

النظام:
- 15 سؤالًا بالترتيب.
- لا يوجد زر رجوع للسؤال السابق.
- بعد إرسال الإجابة ينتقل تلقائيًا للسؤال التالي.
- كل إجابة صحيحة = 10 درجات في نتيجة التحدي.
- كل إجابة صحيحة = +0.5 نقطة في رصيد المنصة لأول مرة فقط لكل سؤال.
- الحد الأعلى لنتيجة التحدي = 150 درجة.
- الحد الأعلى للنقاط الجديدة في رصيد المنصة = 7.5 نقاط إذا كانت كل الأسئلة جديدة على الطالب وأجاب عنها صحيحة.
- إعادة السؤال لا تضيف +0.5 مرة ثانية.

ملاحظة:
ملف SQL يتجاهل السؤال إذا كان موجودًا مسبقًا بنفس العنوان، لذلك يمكن تشغيله مرة ثانية بدون إنشاء نسخة مكررة من نفس المجموعة.
