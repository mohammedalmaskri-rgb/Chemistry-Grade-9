تحديث بنك الأسئلة - تحكم المعلم بإظهار درس كامل

1) شغّل add_lesson2_15_hidden.sql مرة واحدة في Supabase لإضافة 15 سؤالًا للدرس الثاني وهي مخفية.
2) ارفع إلى GitHub واستبدل فقط:
   - index.html
   - question-bank-addon.js
   - question-bank-addon.css
3) لا تستبدل app.js.
4) في حساب المعلم > بنك الأسئلة > اسم الدرس، اختر "فصل وتنقية المواد".
5) سيظهر زر: "إظهار أسئلة هذا الدرس للطلاب". اضغطه بعد إنهاء الدرس.
6) يوجد أيضًا زر لإخفاء أسئلة الدرس مرة أخرى.

التحديث يحافظ على حالة إظهار الحل لكل سؤال، ولا يغيّر نقاط الطلاب أو الحسابات أو الدرجات.
