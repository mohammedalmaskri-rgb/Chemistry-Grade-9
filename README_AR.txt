إصلاح ظهور نقاط بنك الأسئلة في حساب المعلم

1) افتح Supabase > SQL Editor وشغّل teacher_total_points.sql مرة واحدة.
2) في GitHub استبدل app.js فقط بالملف الموجود في هذه الحزمة.
3) لا تستبدل index.html ولا question-bank-addon.js.
4) انتظر GitHub Pages ثم حدّث الصفحة.

بعد الإصلاح تعرض خانة "نقاط الطلاب":
- نقاط المعلم
- نقاط الأسئلة
- المجموع النهائي

مثال: نقاط المعلم 3 + نقاط الأسئلة 6.5 = المجموع 9.5.
